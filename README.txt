MEMORY CAFÉ — SINGLE-PAGE LANDING WEBSITE
=======================================

HOW TO OPEN
1. Extract the entire ZIP archive to a folder.
2. Open index.html in Chrome, Firefox, Edge or Safari.
3. Keep index.html, style.css, images/, and videos/ in the same folder.

PROJECT STRUCTURE
- index.html — semantic HTML5 structure
- style.css — external CSS3 styling and responsive layout
- images/cafe-interior.jpg — café hero photograph
- images/iced-latte.jpg — Iced Latte photograph
- images/matcha-latte.jpg — Matcha Latte photograph
- videos/memory-cafe-introduction.mp4 — locally playable café introduction video

DESIGN AND REQUIREMENTS
- Four sections follow the supplied wireframe: Home, About, Products / Services, Contact.
- Three photographic image assets only, plus one CSS-only croissant illustration.
- One native HTML5 video with local .mp4 source and player controls.
- Exactly three contact-detail icons, drawn using consistent inline SVG paths.
- All visible page content is in English.
- Navigation, View Menu, and Back to Top use working fragment links.
- The contact form is intentionally display-only; it does not send messages.
- Google Fonts are used when internet is available, with Georgia/Arial fallbacks offline.
- No frameworks, external JavaScript or inline CSS.

MEDIA NOTE
The three original illustrative, photographic-style assets were generated for this project.
The accompanying introductory video animates these café images with slow cinematic movement;
it is a locally generated visual montage, not footage of actual baristas or customers.

BEFORE PUBLISHING
- Replace the temporary Address text with the café's actual location.
- Replace hello@memorycafe.example with a real email address when one exists.
- Replace the menu prices and operating hours if your business details differ.
- The form is a visual mock-up, not a functional contact submission service.
